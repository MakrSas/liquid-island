# LiquidIsland

Открытый Dynamic Island для macOS. Работает и на маках с чёлкой, и без неё —
на безрамочных экранах остров просто висит пилюлей поверх меню-бара, как на iPhone.

## Сборка

```bash
./Scripts/bundle.sh release
open build/LiquidIsland.app
```

## Состояния

| Фаза | Что показывает |
|---|---|
| `closed` | Чёрная пилюля. На маках с чёлкой неотличима от выреза. |
| `hovered` | Чуть подрастает под курсором. |
| `activity` | Всплывающая карточка при смене трека: обложка, название, эквалайзер. |
| `expanded` | Полный плеер: обложка, бегущая строка, прогресс, транспорт. |

## Кастомизация

Всё оформление живёт в `~/Library/Application Support/LiquidIsland/theme.json`.
Файл читается на лету — правки видны без перезапуска.
Настраиваются размеры всех фаз, радиусы, палитра, пружины анимаций,
задержки наведения и выбор экрана (`notchedOrMain` / `main` / `followMouse` / `all`).

## Источники Now Playing

1. `MediaRemote` — системный, видит любое приложение. На macOS 15.4+ Apple
   закрыла эти символы, поэтому мост сам проверяет доступность и уступает место
   запасному варианту.
2. AppleScript-мост к Apple Music и Spotify — требует разрешения «Автоматизация».

## Превью дизайна

```bash
swift run LiquidIsland --render-preview ./build/preview
```

Рисует все фазы в PNG без запуска интерфейса — удобно подбирать тему.
