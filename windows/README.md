# Liquid Island для Windows

Порт острова на Windows 11. Кода из версии для macOS здесь нет ни строчки —
переносился замысел: те же состояния, та же схема настроек, то же движение.

## Состояние

Написано, но **ещё ни разу не собиралось**: у автора нет машины с Windows под
рукой. Сборка проверяется через GitHub Actions (`.github/workflows/windows.yml`)
или вручную:

```powershell
cd windows\LiquidIsland
dotnet build -c Release -p:Platform=x64
dotnet run -c Release
```

Нужен .NET 8 SDK и Windows 10 версии 2004 или новее.

## Чем отличается от macOS

**Метаданные проще.** `GlobalSystemMediaTransportControlsSessionManager` —
штатный API без разрешений: отдаёт название, исполнителя, обложку, состояние и
позицию сразу для всех приложений. На macOS то же самое пришлось собирать из
скриптов и звука, потому что системный источник Apple закрыла. Здесь Telegram
и браузер видны наравне с плеером.

**Стекла нет.** Жидкое стекло — эффект macOS 26. Ближайшее в Windows — акрил,
размытие с зерном. Он включается под всё окно, а нужный вид даёт чёрный слой
поверх: непрозрачный сверху, растворяющийся книзу. Ровно тот же приём, что и на
macOS, только вместо стекла размытие.

**Эквалайзер слушает настоящий звук** — WASAPI в режиме loopback. И вот
приятная разница: разрешения для этого в Windows не нужно, тогда как на macOS
под тот же перехват требуется согласие пользователя. Расчёт перенесён тот же:
окно Ханна, преобразование Фурье, полосы по логарифмической шкале.

**Чёлки нет ни у кого**, поэтому остров всегда врастает в верхнюю кромку
экрана — тот режим, который на маке включается для машин без выреза.

## Настройки

Файл лежит в `%APPDATA%\LiquidIsland\theme.json` и читается на лету. Схема
совпадает с версией для macOS с точностью до пары ключей: вместо
`useLiquidGlass` здесь `useAcrylic`, а из списка экранов убран вариант с чёлкой.

## Что осталось

- **Размытие под нижней частью раскрытого острова.** Акрил включается на всё
  окно целиком, а окно прозрачное и во всю ширину экрана — вместо острова
  выходил чёрный прямоугольник. Правильный путь: отдельное окно с размытием
  ровно под фигурой.
- Окно настроек: сейчас правится только файл
- Предупреждение о низком заряде рисуется обычной плашкой, без кнопки
- Свайп по тачпаду: сейчас листание источников колесом мыши
